### 🚧 Projects

**[Sistem Arisan Digital](https://github.com/Bintang444/arisan)**  
Replaced a paper notebook with a proper system — my mother's arisan group uses it every day. Built with Next.js and Supabase; duplicate payments are blocked at the database level with a unique constraint, not just a UI check.

**[Sistem Data Warga](https://github.com/Bintang444/sistem-data-warga)**  
Resident data management for an RT — Indonesia's smallest neighborhood administrative unit. A public timeline with search and filtering for residents, plus an admin dashboard locked down with Supabase Row Level Security so only authorized accounts can edit data. Next.js + Supabase.

**[MyParkirGua](https://github.com/Bintang444/myparkirgua)** · [live demo](https://myparkirgua.vercel.app)  
My UKK project (Indonesia's vocational-school final competency exam) — an IoT parking system on real ESP32 hardware with RFID-based access and live dashboards for staff and owners. Vanilla JS + Supabase + MQTT.

**Student Management System** — [Android app](https://github.com/Bintang444/aplikasi-manajemen-siswa) · [backend API](https://github.com/Bintang444/backend-manajemen-siswa)  
Full-stack system built during my internship at BBPPMPV BMTI, a government vocational-training center. A Kotlin Android app talks to a PHP REST API backed by MySQL.
